# 📚 Book Recommendation System using K-Means Clustering

## 📌 Project Overview
This project is a **Book Recommendation System** built using **Flask**, **Pandas**, and a **K-Means clustering model**.  
It recommends books based on user inputs such as:
- **Average Rating**
- **Number of Reviews**
- **Number of Pages**

The K-Means model groups books into clusters, and the system recommends books from the cluster that best matches the user's preferences.

---

## 🚀 Features
- Interactive **Flask Web App** for book recommendations
- **K-Means clustering** for grouping similar books
- **CSV dataset** containing clustered book details
- Dynamic recommendations (up to 5 books)
- Error handling for invalid inputs
